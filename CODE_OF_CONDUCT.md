# Code of Conduct

## The short version

Be decent. Assume the other person is acting in good faith. Criticise code, not
people.

## Expected behaviour

- Keep discussion technical and specific. "This breaks on Windows because paths
  are joined with `/`" is useful; "this is badly written" is not.
- Accept that maintainers may decline a change. Scope is a judgement call and
  a no is not a personal verdict.
- Respect that contributors work across time zones, first languages and
  experience levels.

## Unacceptable behaviour

- Harassment, insults, or personal attacks
- Demeaning comments about anyone's identity, background or ability
- Publishing someone's private information
- Sustained disruption of issues or pull requests

## Scope

This applies in issues, pull requests, commit messages, and any other project
space, including when representing the project elsewhere.

## Reporting

Report privately through GitHub Security Advisories, which is the only private
channel this project has:

https://github.com/Bilalkpoecs/khud/security/advisories/new

Reports are read by the maintainer. Expect a reply within 7 days. Consequences
range from a warning to a permanent ban from project spaces, depending on
severity and pattern.
